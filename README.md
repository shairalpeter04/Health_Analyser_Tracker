# Health Analyser & Tracker

## About the Project

Health Analyser & Tracker is a Python console application that
assists users to log and analyze basic daily health-related activities.

The application provides the user with the ability to enter his/her profile,
calculate BMI, log daily intake of water, sleep, steps and exercises, and get
basic analysis of health and health report.

This project has been created as an educational Python project.

## Features

- User Profile
- BMI Calculation
- BMI Category
- Daily Health Records
- Multiple Record Management
- Average Calculation
- Most Steps
- Least Steps
- Health Analysis
- Health Score
- Final Health Report
- Input Validation

## Technologies
